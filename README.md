## 📌 Descripción

Este proyecto consiste en un sitio web tipo **One Page Portfolio**, diseñado para presentar de manera clara y profesional mi perfil como desarrollador de software junior.

La página reúne información sobre mi formación, habilidades técnicas, proyectos destacados y medios de contacto, utilizando una interfaz moderna, responsive y enfocada en una navegación sencilla.

El proyecto fue construido desde cero utilizando tecnologías web fundamentales, sin depender de frameworks frontend.

---

## 🎯 Objetivos del proyecto

- Crear una presentación profesional de mi perfil tecnológico.
- Aplicar conocimientos de **HTML5, CSS3 y JavaScript**.
- Implementar una estructura web semántica y organizada.
- Diseñar una interfaz adaptable a diferentes tamaños de pantalla.
- Incorporar microinteracciones y animaciones para mejorar la experiencia de usuario.
- Mostrar proyectos desarrollados durante mi formación.
- Practicar buenas prácticas de organización de archivos y control de versiones con Git/GitHub.
- Construir una base que pueda seguir evolucionando a medida que adquiera nuevas habilidades.

## 🧰 Tecnologías utilizadas

### 📄 `index.html`

Es el archivo principal del proyecto. Contiene toda la estructura del portafolio y las diferentes secciones de la página.

### 🎨 `css/styles.css`

Contiene estilos globales, variables CSS, tipografía, colores, espaciados, componentes del formulario, accesibilidad y animaciones generales.

### 📐 `css/layout.css`

Gestiona principalmente la estructura visual del sitio:

- Header.
- Navbar.
- Hero.
- Tarjeta de código.
- Sección Sobre mí.
- Habilidades.
- Tarjetas informativas.

### 🚀 `css/Proyectos.css`

Contiene los estilos específicos de la sección de proyectos, incluyendo:

- Tarjetas de proyectos.
- Grid responsive.
- Etiquetas tecnológicas.
- Proyecto destacado.
- Efectos `hover`.
- Colores temáticos por proyecto.

### ⚙️ `js/script.js`

Contiene la lógica de interacción del sitio mediante JavaScript Vanilla.

### 📁 `assets/`

Directorio reservado para recursos gráficos del proyecto, como imágenes e iconos.

## ▶️ Cómo ejecutar el proyecto

Este proyecto no requiere instalación de dependencias.

### Opción 1 — Abrir directamente

Descarga o clona el repositorio y abre:

```text
index.html
```

en cualquier navegador moderno.

### Opción 2 — Utilizar Live Server

Si utilizas Visual Studio Code:

1. Abre la carpeta del proyecto.
2. Instala la extensión **Live Server**.
3. Haz clic derecho sobre `index.html`.
4. Selecciona **Open with Live Server**.

Esto permite visualizar los cambios en tiempo real mientras se desarrolla el proyecto.

## 🔧 Personalización

Para utilizar este proyecto como base de otro portafolio, se pueden modificar principalmente:

### Información personal

Editar el contenido de `index.html`:

- Nombre.
- Descripción.
- Formación.
- Habilidades.
- Información de contacto.

### Proyectos

Dentro de la sección `#proyectos` se pueden modificar:

- Nombre del proyecto.
- Descripción.
- Enlace al repositorio.
- Tecnologías utilizadas.
- Color temático.

### Estilos

Los colores principales pueden modificarse desde las variables definidas en:

```text
css/styles.css
```

Por ejemplo:

```css
--accent-primary
--accent-primary-hover
--accent-secondary
--bg-primary
--bg-secondary
```
