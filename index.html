Chatbot de Asesorías (TutorBot)

Destacado

Agente inteligente diseñado para automatizar integralmente la gestión, reserva y seguimiento de tutorías académicas. Implementado mediante arquitecturas de flujos en n8n e integrando modelos de IA generativa, el sistema conecta de forma directa la plataforma de mensajería de Telegram con Google Sheets como base de datos operacional. n8n IA Generativa Telegram API Google Sheets
